# Amornphan POS (ร้านอมรภัณฑ์)

เว็บระบบขายหน้าร้าน สร้างจากระบบดีไซน์ "Amornphan POS" ใช้งานได้ทันที ไม่ต้องติดตั้งอะไร

## เว็บออนไลน์
https://jordanbookkeee.github.io/amornphan-pos/ (GitHub Pages จาก repo `Jordanbookkeee/amornphan-pos`)

อัปเดตเว็บ: แก้ไฟล์ในโฟลเดอร์นี้ → รัน `build.ps1` เพื่อสร้าง `dist/index.html` ใหม่ (ไฟล์เดียวที่รวมทุกอย่าง) → อัปโหลดทับใน repo

## ซิงก์ข้ามเครื่อง (Firebase)
- โปรเจกต์ Firebase `amornphan-pos` (Firestore ที่สิงคโปร์ แพ็กเกจ Spark ฟรี) ค่าตั้งค่าอยู่ใน `firebase-config.js`
- ทุกเครื่องล็อกอินด้วยบัญชีร้าน bookpongsagorn@gmail.com แล้วเห็นข้อมูลเดียวกัน ขายตอนเน็ตหลุดได้ ข้อมูลจะส่งขึ้นเองเมื่อเน็ตกลับมา
- กฎความปลอดภัยใน `firestore.rules` ให้อ่าน/เขียนได้เฉพาะบัญชีร้าน (ตั้งไว้ใน Firebase console › Firestore › Rules แล้ว)
- สต็อกส่งเป็น "ส่วนต่าง" สองเครื่องขายของชิ้นเดียวกันพร้อมกันก็นับถูก
- โหลดบิลย้อนหลัง 120 วันมาแสดง (บิลเก่ากว่านั้นยังอยู่ในฐานข้อมูล)
- ตั้ง `window.FIREBASE_CONFIG = null` ใน `firebase-config.js` ถ้าจะกลับไปใช้แบบเก็บในเครื่องอย่างเดียว

## วิธีเปิด
ดับเบิลคลิก `index.html` (แนะนำ Chrome หรือ Edge) ใช้แบบออฟไลน์ได้ ข้อมูลทั้งหมดเก็บในเบราว์เซอร์ของเครื่องนั้น

- PIN เจ้าของร้านตัวอย่าง: `1234` (เปลี่ยนได้ใน ตั้งค่า › ผู้ใช้งานและ PIN)
- สำรองข้อมูล: ตั้งค่า › สำรองข้อมูล › ดาวน์โหลดไฟล์สำรอง (ควรทำสัปดาห์ละครั้ง)
- ใบเสร็จพิมพ์ผ่านหน้าต่างพิมพ์ของเบราว์เซอร์ (58/80mm)

## สองร้านในแอปเดียว
ปุ่ม "เครื่องเขียน / พัสดุ" บนแถบด้านบน สลับร้านและสีธีมทันที (ร้านพัสดุใช้ธีมส้ม)
- สินค้า สต็อก บิล รายงาน และการปิดยอดแยกกันตามร้าน ตะกร้าก็แยกกัน บิลร้านพัสดุขึ้นต้นด้วย P-
- ร้านพัสดุขายกล่องตามขนาด (00 – F) เป็นใบหรือแพ็ก 20 พิมพ์ขนาดในช่องค้นหา เช่น `B` แล้วกด Enter ได้เลย
- ราคากล่องเป็นราคาสมมติ แก้ได้ในหน้าสินค้า (ตอนอยู่ร้านพัสดุ)
- การตั้งค่า PIN และข้อมูลร้านใช้ร่วมกันทั้งสองร้าน

## บิลเงินสด A5
ประวัติบิล › "ออกบิลเงินสด A5": กรอกรายการเอง (สูงสุด 14 แถว) มีจำนวนเงินเป็นตัวอักษรไทยให้อัตโนมัติ
- กระดาษ **A4 แนวนอน** (ค่าเริ่มต้น): บิลเดียวกัน 2 ฉบับต่อแผ่น ตัดตามเส้นประตรงกลาง
- "จำนวนบิลที่ออก": ออกบิลรายการเดียวกันหลายใบในครั้งเดียว เลขที่เรียงต่อกัน (เช่น 30 ใบ = 0001–0030, A4 15 แผ่น) ทุกใบถูกบันทึกแยก และเลขที่ถัดไปเลื่อนตาม หรือเลือก A5 1 ใบ/แผ่น
- "บิลที่ออกแล้ว": ปุ่มดินสอเปิดบิลเก่ามาแก้ไข (บันทึกหรือพิมพ์แล้วจะแทนที่บิลเดิม เลขที่เดิม ไม่สร้างบิลใหม่) · พิมพ์ซ้ำทีละใบ ติ๊กเลือกหลายใบแล้วพิมพ์รวดเดียว และลบบิลได้ (ต้องใส่ PIN)
- "ข้อมูลร้านบนบิล": เลือก "เว้นว่างไว้ปั๊ม" (ค่าเริ่มต้น กรอบหัวบิลว่างไว้ปั๊มตรายาง) หรือ "พิมพ์ชื่อร้าน" ใช้กับการพิมพ์ทุกแบบรวมถึงฟอร์มเปล่าและพิมพ์ซ้ำ
- ข้อมูลหัวบิล (ชื่อร้าน ที่อยู่ โทร เลขผู้เสียภาษี เล่มที่ เลขที่ถัดไป) ตั้งครั้งเดียว ซิงก์ทุกเครื่อง
- บิลที่บันทึกหรือพิมพ์จะเก็บไว้ แยกตามร้าน ดูและพิมพ์ซ้ำได้จากปุ่ม "บิลที่ออกแล้ว"
- ตอนพิมพ์ให้เลือกกระดาษ A5 ในหน้าต่างพิมพ์ และมีปุ่ม "พิมพ์ฟอร์มเปล่า" ไว้เขียนด้วยมือ
